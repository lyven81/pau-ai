Apa Ia Buat

MCP Tools Atas Database Sebenar Awak. Bukan Dashboard.

Kita connect LLM (Claude / Gemini / pilihan awak) ke data sebenar awak via Model Context Protocol tools. Agent call tools macam getRevenueByDay, getTopSKUs, comparePeriods — running SQL sebenar atas database sebenar awak — dan synthesize answer dalam plain language.

Tiada lagi report umur sebulan. Tiada lagi 'I'll get back to you next week.' Tanya 'which 3 products lost margin in Q4?' dan dapat answer dalam 8 saat, dengan underlying numbers shown.

Macam Mana Ia Berfungsi

Tiga Langkah Untuk Tanya Data Awak

1

Connect Data Awak

Kita hook up AlloyDB, Cloud SQL, Google Sheets, atau POS export awak. Read-only by default. Awak keep semua data dalam environment awak.

2

Define MCP Tools

Kita design 8–15 typed tools yang match soalan yang awak betul-betul tanya: revenue, inventory, customer, time-period comparisons.

3

Tanya Dalam Plain Language

Voice atau text. Agent call right tools, run real queries, dan jawab dengan numbers + brief insight.

Soalan Biasa Sebelum Commit

Dashboard adalah static — ia tunjuk apa yang someone decide important quarter lepas. Conversational data analytics adalah dynamic — awak tanya whatever question matters hari ni, dan agent run actual query against data sebenar awak.

Awak tak ganti dashboard awak. Awak stop being limited by it. Some clients keep both.

Tak. Database awak tinggal kat tempat ia — AlloyDB awak, Cloud SQL awak, Google Sheets awak. Agent run as service yang connect dengan read-only credentials. Kita tak copy data out, dan kita handover full access ke awak at delivery. Agent run kat hosting account awak.

Most SME data memang messy. Kita spend first week of build understanding data shape awak dan either (a) consolidate ia via small ETL ke AlloyDB, atau (b) build MCP tools yang query each source separately dan synthesize answers. Either works.
