API key awak duduk dalam environment awak — bukan kami. Kami tidak store, access, atau handle API key awak selepas handover. Semua API call pergi terus dari system awak ke provider pilihan awak. Kami berada di luar loop tu sepenuhnya. Lihat polisi penuh API key dalam FAQ →
Apa Itu API Key

Kunci Duduk Dalam Environment Awak. Bukan Kami.

API key awak adalah milik awak sepenuhnya. Bila kami setup sistem awak, kunci tersebut disimpan dalam hosting environment awak sendiri — server awak, cloud account awak, fail .env awak. Pau AI tidak store, access, atau retain API key awak pada bila-bila masa, termasuk semasa development dan testing.

Semua request dari sistem awak pergi terus ke LLM provider pilihan awak (Anthropic, Google, OpenAI, dll). Kami tidak pernah dalam laluan data. Kalau awak nak revoke atau rotate key, awak buat terus dengan provider — tiada tindakan diperlukan dari kami.
