常见问题 · Agentic Commerce

决定前的常见疑问

WebMCP 是 W3C 标准(在 Chrome 146+ 中推出),让 AI agent 能调用网站上的 typed 工具 — 像是网页版的 API。没有它,AI agent 必须读取截图并模拟点击按钮,这样既慢又脆弱、容易出错。

你需要它,因为消费者 AI agent 已经开始代表用户下真实订单。如果你的业务不是 agent 可调用的,你就在这股流量中是隐形的。

能。WebMCP 商店是普通的浏览器页面,带有一个隐藏的 agent 可调用层。人类看到完整的 UI,正常点击按钮。AI agent 读取 typed 工具元数据并直接调用。两者并行运行。

结构化数据(schema.org JSON-LD)告诉搜索引擎你的页面是什么。WebMCP 工具让 agent 做事 — 调用函数、检查实时可用性、创建预订、用实时价格获取报价。这是 agent 阅读你的菜单与 agent 真正下单之间的差别。

Chrome 146+ 已经发布 WebMCP 支持。Claude Desktop 和几个 agent 浏览器今天就能调用 WebMCP 工具。大规模采用是 2026–2028。现在搭建意味着浪潮到来时你就能被发现 — 而不是事后赶不上。

能。打开上面链接的 Sunny Car Accessories demo。两者都完全 agent 可调用。用 Chrome 146+ 看到 WebMCP 层的实际运作,或用 Claude Desktop 配合正确配置。我们会在对接电话上带你走一遍。
