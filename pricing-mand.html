什么是 API Key

钥匙在你的环境里。不在我们手上。

你的 API key 完全归你所有。当我们为你搭建系统时,key 存放在你自己的托管环境中 — 你的服务器、你的云账户、你的 .env 文件。Pau AI 不会在任何时候存储、访问或保留你的 API key,包括开发和测试期间。

所有来自你系统的请求直接发往你选择的 LLM 供应商(Anthropic、Google、OpenAI 等)。我们从不在数据路径中。如果你想吊销或轮换密钥,你直接与供应商完成 — 不需要我们做任何操作。
